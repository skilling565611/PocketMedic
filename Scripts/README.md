# Scripts

Place maintenance and automation scripts here.

Scripts in this folder can be executed directly from the PocketMedic
TerminalUI or Dashboard.  Both `.py` and `.bat`/`.sh` scripts are supported.

Example scripts:
- `clear_temp.py` — Clears the Windows Temp folder
- `flush_dns.bat` — Flushes the DNS resolver cache
- `defrag_check.py` — Reports fragmentation levels
