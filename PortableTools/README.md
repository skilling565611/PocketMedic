# PortableTools

Drop portable (no-install) executables and utilities into this directory.

PocketMedic will scan this folder at startup and make the tools available
via the Installer and TerminalUI menus.

Example tools to place here:
- `autoruns.exe` (Sysinternals)
- `procexp.exe` (Sysinternals Process Explorer)
- `CrystalDiskInfo.exe`
- `HWiNFO64.exe`
